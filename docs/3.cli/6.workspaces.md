# workspaces

`ajs dms workspaces` lists the workspaces the CLI generated under `~/.antelopejs/dms-frontend`, with the backend each one serves, what it is keyed on, its size and its last use. It runs from any directory.

```text
$ ajs dms workspaces --help
Usage: ajs dms workspaces [options]

List generated workspaces, with their size and last use.

Options:
  --json                 Print the list as one JSON document on stdout
  -h, --help             Show help for a command

Piped, it prints one tab-separated line per workspace, without a header:
id, backend URL, key type (url or project), project directory, size in bytes,
last use (ISO 8601) and workspace directory.
```

## On a terminal

The two workspaces below serve the same backend: the first one `ajs dms dev` created without `-b`, keyed on the project it ran in; the second one `prepare -b`, `build -b` and `start -b` share, keyed on the URL. This excerpt keeps only those two entries.

```text
$ ajs dms workspaces
ID         8aa5ac7c
BACKEND    http://127.0.0.1:5050
KEY        project .
SIZE       301 MB
LAST USED  3 min ago

ID         8532f40f
BACKEND    http://127.0.0.1:5050
KEY        url
SIZE       324 MB
LAST USED  6 min ago
```

A workspace takes a few hundred megabytes, mostly its `node_modules`. [Workspaces and cache](/docs/frontend/deployment/workspaces-and-cache) explains how they are keyed and what they hold; [`ajs dms clean`](/docs/frontend/cli/clean) removes them.
